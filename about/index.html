칠.space 소개

소셜한 기분, 네트워크는 필요 없어요.

칠.space란?

칠.space는 플라시보 소셜 미디어 네트워크입니다. 게시하고, 좋아요를 누르고, 댓글을 다는 소셜 미디어의 의식(ritual)을 메인스트림 사이트의 중독성 있는 도파민 루프 없이 제공하는 시뮬레이션 소셜 플랫폼입니다. 소셜 미디어를 스크롤하는 기분을 느끼게 해주지만, 소셜 미디어는 아니며, 당신을 행복하게 하도록 설계되었습니다.

슬로건은 “소셜한 기분, 네트워크는 필요 없어요”입니다. 핵심은 연결의 느낌이지, 그것을 수익화하는 네트워크 효과가 아니기 때문입니다.

왜 존재하나요?

대부분의 소셜 미디어는 당신을 화나고 슬프게 만들어, 가끔 주는 작은 행복을 계속 쫓게 만듭니다. 그 메커니즘을 변동 도파민이라고 합니다: 어떤 때는 행복하게 하는 것을 보고, 어떤 때는 화나게 하는 것을 봅니다. 그 예측 불가능성이 당신을 계속 스크롤하게 만듭니다. 슬롯머신과 같은 심리입니다 — 스크롤할 때마다 한 번의 스핀인 셈입니다.

칠.space는 변동 도파민을 일관된 도파민으로 대체합니다. 모든 게시물은 기분 좋게 남도록 설계되었기 때문에, 중독되지 않고도 만족할 수 있습니다. 목표는 간단합니다: 행복을 찾도록 도와, 계속 찾아 헤매지 않게 하는 것입니다.

무엇이 다른가요?

  • 알고리즘 타임라인 없음. 게시물은 무작위 순서로 나타나며, 참여를 유지하도록 최적화되지 않습니다.
  • 푸시 알림 없음. 울리지도, 재촉하지도, 불안 루프도 없습니다.
  • 참여 최적화 없음. 분노 유발(rage-bait)도, 참여 파밍도 없습니다 — 토론 게시물조차 가벼운 분위기입니다.
  • 데이터 수집 없음. 칠.space는 어떤 데이터도 수집하지 않습니다. 방문자 카운터조차 없습니다. Cloudflare는 사이트 호스팅을 위해 필수 데이터를 수집하지만, 칠.space 자체는 아무것도 수집하지 않습니다. 안드로이드 앱은 인터넷 없이 작동하므로, 앱을 사용할 때 Cloudflare조차 데이터를 받지 않습니다.
  • 광고 없음. 칠.space에는 광고가 없으며, Google Analytics나 다른 광고 및 추적 기술을 사용하지 않습니다.
  • 계정 필요 없음. 계정을 만들거나 로그인할 필요가 없으며, 쿠키 팝업을 닫을 필요조차 없습니다.

거기서 실제로 무엇을 하나요?

당신을 행복하게 하도록 설계된 재미있고 무작위적인 게시물 피드를 봅니다. 게시할 수 있고, 좋아요를 보장받습니다 — 실제 사람이 아니어도 기분 좋게 만드는 플라시보 좋아요입니다. 일일 챌린지(Daily Challenge)도 있어, 스스로를 자랑스러워할 작은 무언가이자 행복할 또 하나의 이유가 됩니다. 안드로이드 앱을 사용하면 인터넷 없이도 칠.space 플라시보 피드와 ReelSpace 영상 피드를 스크롤할 수 있습니다 — 비행기 안에서도요.

칠.space 패밀리

칠.space는 실제 비용 없이 만족스러운 시뮬레이션이라는 같은 원칙으로 만들어진 여러 플라시보 도구 중 하나입니다.

  • ReelSpace — TikTok, Shorts, Reels의 마음챙김 짧은 영상 대안. 강박적 스크롤 대신 의도적인 시청을 장려합니다.
  • ChillSpace Shop — SHEIN 쇼핑 경험을 모방한 시뮬레이터: 실제 구매나 재정적 결과 없이 둘러보고, 장바구니에 담고, 결제합니다.
  • BuyVinyl — 바이닐 레코드 주문 시뮬레이터. 레코드를 “받으면” 사이트가 실제 음악을 회전하는 레코드 애니메이션과 함께 재생합니다.
  • Number Game — 광고도, 소액 결제도 없는 순수 클리커 게임. 중독 루프 없이 진행의 만족감을 줍니다.

공식 사이트 및 링크

다음 도메인만 공식 칠.space 목적지입니다. 이름을 사용하는 다른 모든 것은 다른 프로젝트입니다.

칠.space 공식 한국어 사이트 chillspace.ai 공식 영어 및 국제 사이트 Chrome 확장 프로그램 X, Twitter, Facebook, Reddit을 칠.space로 바꿔줍니다 Google Play 안드로이드 앱 — 오프라인 스크롤, 비행기에서도 ReelSpace 마음챙김 짧은 영상 ChillSpace Shop 지출 없는 SHEIN BuyVinyl 가짜 바이닐, 진짜 음악
칠.site, 칠.online, chill-space.pages.dev, chillspace.site.je, optu.be도 칠.space를 호스팅하지만, 메인 웹사이트는 아닙니다.

짧은 역사

도파민 사이트 트렌드는 2026년 초 일본에서 시작되어, 한국 미디어가 젊은이들이 비용, 중독, 기타 결과 없이 짧은 자극을 추구한다고 보도하면서 한국으로 퍼졌습니다. 칠.space는 그 운동에서 성장했으며, 이후 가장 프라이버시 친화적인 사례 중 하나가 되었습니다.

  • 2026년 4월 2일원래 한국 도파민 음식 배달 사이트 도메인 등록.
  • 2026년 6월 26일칠.space, chillspace.site.je에서 오픈.
  • 2026년 7월 23일소스 코드, AGPL-3.0 라이선스로 GitHub에 공개.
  • 2026년 8월 11일ChillSpace Shop 오픈.
  • 2026년 8월 20일BuyVinyl 출시, 레코드 “수령” 후 실제 음악 재생.
  • 2026년 8월 27일칠.space, chillspace.ai로 이전.
  • 2026년 9월안드로이드 앱, Google Play, Amazon Appstore, GitHub Releases, APKPure에 com.chillspace.app으로 출시.

자주 묻는 질문

칠.space는 진짜 소셜 네트워크인가요?
플라시보 소셜 미디어 네트워크입니다. 게시하고, 답글 달고, 좋아요를 누르고, 메시지를 보낼 수 있지만, 목적은 당신을 참여 루프에 가두는 것이 아닙니다. 만족을 주도록 설계된 차분한 시뮬레이션 소셜 경험입니다.
칠.space는 제 데이터를 수집하나요?
아니요. 칠.space는 어떤 데이터도 수집하지 않습니다. 방문자 카운터조차 없습니다. Cloudflare는 사이트 호스팅을 위해 필수 데이터를 수집하지만, 칠.space는 아무것도 수집하지 않습니다. 앱은 인터넷 없이 작동하므로, 앱을 사용할 때 기기 밖으로 나가는 데이터는 없습니다.
다른 소셜 미디어와 칠.space의 차이는 무엇인가요?
칠.space는 변동 도파민 메커니즘을 제거했습니다. 분노, 두려움, 시기를 유발해 계속 스크롤하게 만드는 콘텐츠 대신, 모든 게시물이 기분 좋게 설계되었습니다. 그 결과, 지치지 않고 만족하며 떠날 수 있는 피드가 됩니다.
계정이 필요한가요?
아니요. 계정을 만들거나 로그인할 필요가 없으며, 쿠키 팝업을 닫을 필요조차 없습니다.
앱이 있나요?
네. 안드로이드 앱은 Google Play, Amazon Appstore, GitHub Releases, APKPure에서 이용할 수 있습니다. 설치하면 인터넷 없이도 칠.space 플라시보 피드와 ReelSpace 영상 피드를 스크롤할 수 있습니다 — 비행기 안에서도요.
칠.space는 오픈 소스인가요?
네, AGPL-3.0 라이선스입니다. 웹 버전은 github.com/op-tube/chillspace에, 안드로이드 앱은 github.com/op-tube/ChillSpaceApp에 있습니다.
어떤 칠.space가 진짜인가요?
공식 사이트는 두 곳입니다: chillspace.ai (영어 및 국제)와 칠.space (한국어). 둘 다 완전한 칠.space 경험을 제공합니다 — 작동하는 개인정보 처리방침, 소셜 피드, 통합 메시징, 게임, AI, 로컬 데이터 저장 — 다만 중독성만 없습니다. 칠.space라는 이름을 사용하는 다른 사이트들은 AI 데이팅 시뮬, 시적 예술 프로젝트, 정적 갤러리, 또는 정체불명의 JSON 페이지입니다. chillspace.ai 또는 칠.space를 찾으세요.
칠.space는 플라시보 소셜 미디어 플랫폼입니다. 알고리즘 없음. 광고 없음. 데이터 수집 없음.
